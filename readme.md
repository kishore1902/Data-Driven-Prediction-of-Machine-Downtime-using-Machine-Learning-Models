# Data-Driven Prediction of Machine Downtime Using Machine Learning Models

An end-to-end machine learning project focused on predicting machine downtime from operational data. The project applies data analysis and machine learning techniques to identify patterns associated with equipment downtime and support data-driven maintenance decisions.

## 🚀 Live Demo

**Try the application:** [Machine Failure Impact Prediction System](https://machine-failure-impact-prediction-system.streamlit.app/)



## 📌 Project Overview

Unexpected machine downtime can disrupt industrial operations, reduce productivity, and increase maintenance costs. Analyzing operational data can help identify patterns associated with downtime and support better maintenance planning.

This project explores machine downtime prediction using machine learning models and provides a deployed web application through which users can interact with the prediction system.

The project covers data-driven analysis, model development, performance evaluation, and deployment.

## 🎯 Objectives

- Analyze machine-related operational data to identify patterns associated with downtime.
- Prepare and preprocess data for machine learning.
- Train and evaluate machine learning models for downtime prediction.
- Compare model performance to identify a suitable predictive model.
- Deploy an interactive application for exploring machine failure predictions.
- Demonstrate how machine learning can support predictive maintenance decisions.

## ✨ Key Features

- **Data-Driven Analysis:** Explore operational data to understand factors associated with machine downtime.
- **Data Preprocessing:** Prepare input data for machine learning model training and prediction.
- **Machine Learning Models:** Apply and compare machine learning algorithms for predictive analysis.
- **Model Evaluation:** Assess model performance using appropriate evaluation metrics.
- **Interactive Web Application:** Access the prediction system through a Streamlit interface.
- **Cloud Deployment:** Use the deployed application without setting up the project locally.

## 🔄 Project Workflow

1. **Data Collection:** Load the machine-related dataset used for the prediction task.
2. **Data Preprocessing:** Clean the data and prepare the relevant features.
3. **Exploratory Data Analysis:** Examine distributions, relationships, and patterns in the data.
4. **Feature Preparation:** Select and transform the input variables required by the models.
5. **Model Training:** Train machine learning models using the prepared dataset.
6. **Model Evaluation:** Compare the trained models using suitable evaluation metrics.
7. **Prediction:** Use the selected model to generate predictions from input data.
8. **Deployment:** Make the prediction system accessible through a Streamlit web application.

## 💻 Run the Project Locally

### Prerequisites

- Python 3.10 or a compatible version
- pip
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/kishore1902/Data-Driven-Prediction-of-Machine-Downtime-using-Machine-Learning-Models.git
```

Navigate to the project directory:

```bash
cd Data-Driven-Prediction-of-Machine-Downtime-using-Machine-Learning-Models
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

### 3. Install Dependencies

If the repository contains a `requirements.txt` file, install the dependencies using:

```bash
pip install -r requirements.txt
```

### 4. Launch the Application

If the Streamlit entry point is `app.py`, run:

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal to interact with the application.

*Use the actual application filename and setup instructions from the repository if they differ.*
